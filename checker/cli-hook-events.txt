# WHY THIS FILE EXISTS. RoT MoE's event list was previously derived by counting
# which events other installed plugins bound. That is a lower bound: it cannot
# reveal an event nothing on the machine happens to use, and it missed twenty-two
# of the thirty-three below. A fixture extracted from the CLI removes the guesswork
# and, more importantly, gives checker/cli-event-coverage.sh something to fail
# against when a CLI upgrade adds an event the router does not yet bind.
#
# ORDER IS THE CLI'S OWN and is significant: hooks/hooks.json, ARM_ROUTER.sh,
