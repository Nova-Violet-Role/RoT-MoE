# CP5 — the CI was red for four different reasons, and none of them was visible

Checkpoint Resumee, 2026-08-05. Every claim names its instrument.

## What was actually wrong

The previous release commit had been pushed with CI **unverified** (API rate
limit, no `gh`). It was red. So was the one before it. Four distinct defects,
none of which reproduced on this machine:

| # | defect | where it hid |
|---|---|---|
| 1 | `set -o pipefail` + `grep -q` = SIGPIPE 141 on a **successful match** | a RACE — green here, red on ubuntu |
| 2 | `sh ARM_ROUTER.sh` where `sh` is dash and the script uses `BASH_SOURCE` | Git Bash `sh` *is* bash |
| 3 | `sed -i "$expr" file` — BSD sed takes the expr as a backup suffix | macOS only |
| 4 | `head -n -1` — a GNU extension BSD head rejects | macOS only, in a *control* |

Plus two of my own: a checkpoint note quoting absolute local paths, and two new
`.sh` files at mode 100644 in the index.

## The instrument that made all of it findable

`actions/runs/<id>/logs` answers **403 — "Must have admin rights to
Repository"** to an unauthenticated caller. On a **public** repo the only
readable evidence was the check-run annotation, and it said, in full:

```
failure: Process completed with exit code 1.
```

`::error::` lines *become* annotations, and annotations *are* public. Three
checkers now emit one per failure, guarded on `GITHUB_ACTIONS`. The next macOS
run immediately said:

```
log-replay | CONTROL DISCARDED: a wrong sigma -- the corruption did not apply,
             so NOTHING was tested
```

That is defect #3, named by the checker itself. **Two lines of `::error::` did
what an hour of speculation could not.** Control: appending a real `curl` to
`hooks/rot-router.sh` produced the annotation at exit 1; restored byte-identical,
exit 0; green runs emit zero.

## Three more defects fell out of the sweep

1. **A gate that could not pass.** `release-session.sh` recovered the release map
   by `sed`-ing the packager's *source text*. The packager now derives versions
   from `plugin.json`, so it hunted `rot-moe-$_MM.0-core.zip` while the three real
   archives sat in `.release/`. Same defect already fixed in `release-install.sh`
   — the repair reached one sibling, not the other. `release-longsession.sh` was a
   **third** copy. Now **48 passed, 0 failed**.
2. **The rule that would have caught it** — `workflow-lint` rule 6. Its first
   draft flagged the file that had *already been repaired*, because the pattern
   matched the correct form too. A rule whose only cure is to undo the fix is a
   defect in the rule. Tightened, with **two** controls: the broken form must be
   caught **and** the correct form must not be.
3. **The pre-commit gate was gone.** CodeMap overwrote `.githooks/pre-commit`
   wholesale — again. `workflow-lint` caught it: *"pre-commit exists but never
   calls gate-all — it guards nothing"*. Restored; CodeMap's newer hook promoted
   to `.githooks/pre-commit.d/10-codemap` so both survive.

## A classifier repair, proved rather than asserted

`mutant-discipline.sh` selects harnesses by behaviour. Its adjudication test was
`killed|survived|discard|CONTROL` — and `CONTROL` is what every good checker
calls its negative control, so two non-harnesses were failed for missing
`discard-reporting`.

Dropping `CONTROL` *looks* like weakening a check. It is now a **theorem**:

| theorem | says |
|---|---|
| `discipline_applies_to_every_kill` | patches + reports a kill ⇒ selected, over **every** evidence shape |
| `repair_only_narrows` | the new selection is a **subset** of the old — nothing escaped |
| `repair_is_not_vacuous` | …and a **strict** subset, so it is not a no-op dressed as a fix |
| `a_control_alone_is_not_a_harness` | the whole content of the defect |
| `no_patch_no_discipline` | the over-broad direction stays shut |

Plus a `#guard` exhaustive over all **32** evidence shapes pinning exactly where
the two classifiers differ. Measured: 17 files selected before, 15 after, the two
dropped are exactly the two misclassified.

## RotMutant had never been mutated

The module that *defines* mutation discipline had no suite. Now 10 mutants —

counted toward totals, and four aimed at the new classifier:
**10 killed, 0 survived, 0 discarded.** Three needles came back DISCARDED on the
first run and were **fixed**, never folded into survived.
